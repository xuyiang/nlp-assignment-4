# nlp-assignment-4

Fine-tuning BERT on IMDb and training T5 for ATIS flight text-to-SQL, for DS GA 1011 Assignment 4.

- [Part 1](part1/README.md) contains the sentiment classifier, review transformation, augmentation, and reproduction commands.
- [Part 2](part2/README.md) contains the T5 experiments, evaluation, and development error analysis.

The assignment framework and flight data came from the [course starter repository](https://github.com/gregdurrett/nyu-dsga1011-a4).
